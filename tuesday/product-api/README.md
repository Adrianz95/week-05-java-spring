# Product API

## Objetivo
API REST desarrollada con Java y Spring Boot.

## Tecnologías
- Java 21
- Maven
- Spring Boot

## Requisitos
- JDK compatible
- Maven o Maven Wrapper

## Ejecutar
./mvnw spring-boot:run

## Endpoint disponible
GET /products

## Pruebas
./mvnw test

## Estado actual
Primera versión con datos estáticos.

## Próximos pasos

- Crear, actualizar y eliminar productos
- Incorporar persistencia
- Mejorar validaciones y gestión de errores
